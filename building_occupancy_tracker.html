BUILDING OCCUPANCY TRACKER

Personal project - Currently working on

Working on a building occupancy tracker to keep track of the current number of people within a building and provide warnings when this number exceedes saftey thresholds.

  • Detects humans and tracks their position in frame.
  • Occupancy account is incresead when a person crosses the boundary line, and is decresead when a person corses it in the oppsiote direction.
  • Occupancy number is kept track of with early warnings sent to the operator when the number of people inside the space begins to reach the maxium safe limit, with more warnings sent when the number of people corsses this threshold.

Build process so far:

To begin this process I researched into a range of libraries to detect humans and track their postion on frame, I also looked into ways to assgin an idea to each detected bounding box to prevent potential false crossing being registered if the algorithm was to be momentarily interupted.

After I had selected the libraries I wanted to use, I began programming the core logic, intergrating the various libraries togther and connecting them to my laptops video feed, allowing me to test the core logic of the program. Once I had tested this logic, I added saftey warning messages that occurred when occupancy limits were being approached and excceded.

I am now working on connecting multiple video streams from Raspberry Pi's to the program so I can set them up on the tops of doors and test the occupancy tracker on a real room with multiple entries / exits.
